# 0.1.2 维护与验收

网易正式引擎为3.10.5.301327，补丁为3.10.15.301976，资源摘要为a72549110aa25aadee47980bcebdd9e6。官方MCP的MD5为64d96723f961a90c9b1ace553c5bb4e4，SHA256为275ba6bb1f55ad44a5bda76355f33b9dd425f35bb50dfe936563bcb19095b5ec。

三个认证模块的变化经过静态审阅。四个认证方法保持一致，变化涉及未引用的名称、未使用的局部随机常量和错误转储白名单。PE配方与动态MCP工具增加精确版本绑定，运行时继续核对完整动态模块模板。

租赁服协议升级至898，GameVersion为1.21.130。登录封装、资源包回应、区块半径、移动确认和相关NBT编码根据NTvector固定提交ce743787b83944cf39649041f9011919763b41ba逐项核对。[协议参考源码](https://github.com/lurete-cn/NTvector/tree/ce743787b83944cf39649041f9011919763b41ba)

旧协议860在NetworkSettings阶段收到服务端reason35拒绝。898完成了压缩协商、加密登录、初始化、动态MCP回应和只读命令往返。GameVersion和Certificate封装随协议一起适配。

官方manifest获取增加有界GET重取，适用于网络错误、临时HTTP状态和无效ZIP。最多请求3次，退避为0.25秒和0.5秒。永久HTTP错误和无效JSON返回安全错误分类。认证和游戏连接的次数独立记录。

开发版本最终通过一次60秒只读保持和独立10轮首次连接，每轮保持30秒并执行起止探针。游戏重连次数为0，连接和后台任务正常关闭。该序列中的公开清单均首次获取成功。早期冷启动、860拒绝和清单获取失败的记录由维护者保存在本机维护报告中。

开发工作树全量回归为673通过、3项既有mcstructure坏输入测试失败。公开副本保留了先前发布的严格解析修复，公开构建的离线测试结果记录在发布复核文档中。[发布复核](../RELEASE_REVIEW.md)

公开源码以已发布副本为基础应用维护增量，包含原生依赖构建和隐私处理的既有修复，因此其源码摘要与开发工作树不同。上述实服验收对应开发构建。898告示牌和命令方块编码具有离线及模拟writer覆盖，898实服NBT写入和完整建筑验收仍待执行。
